# DevTrack

A Personal Developer Progress Tracker built using Spring Boot.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok

## Features Completed

- ✅ User Management Module
- Create User
- Get All Users
- Get User By ID
- Update User
- Delete User
- Bean Validation
- DTO Pattern
- Global Exception Handling

## Upcoming Modules

- Skill Management
- Project Management
- Daily Logs
- Dashboard
